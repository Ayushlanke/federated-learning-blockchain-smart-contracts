# research/

Curated research material for BC-FL-SRV.

| File | Committed? | Contents |
|---|---|---|
| `RELATED_WORK.md` | yes | Cited prior art with evidence tags — the authoritative reference list |
| `papers/` | **no** (gitignored) | Extracted full text of copyrighted papers, personal research use only |
| `_salvage/` | **no** (gitignored) | Raw search-engine output from the literature sweep |

Nothing in the ignored directories is redistributable. Every claim BC-FL-SRV relies
on is cited in `RELATED_WORK.md` with an evidence tag, so the argument is fully
reconstructible from public sources without them.
